# AI Resume Matcher

Upload a resume, paste a job description, and get a **match score**, **matched / missing skills**, and **LLM-written recommendations**. Built as a full-stack project with hybrid retrieval (embeddings + structured LLM extraction).

**Stack:** Next.js · Node/Express · REST · PostgreSQL + pgvector · Claude API (extraction + recommendations) · Voyage embeddings

## Architecture

```
Next.js UI ──REST──> Express API ─┬─ PostgreSQL (users, resumes, jobs, match_results)
                                  ├─ pgvector   (resume/job chunk embeddings, HNSW cosine index)
                                  ├─ Claude     (skill extraction, recommendations; Zod-validated JSON)
                                  └─ Voyage     (embeddings)
```

## How scoring works

| Component | Weight | How |
|---|---|---|
| Semantic similarity | 50% | For each JD chunk, find its nearest resume chunk with pgvector (cosine), average, rescale 0.3-0.8 to 0-1 |
| Skill overlap | 35% | Required skills fully weighted, nice-to-have at 30%; synonyms normalized (`JS` = `JavaScript`) |
| Experience fit | 15% | `min(1, resume_years / required_years)` |

Missing skills = required skills not found after normalization. Recommendations (what to learn, resume rewrites, project ideas) are generated by Claude from the gaps and validated against a schema.

## Run locally

```bash
docker compose up -d                      # Postgres + pgvector
cd server && cp .env.example .env         # add ANTHROPIC_API_KEY (and VOYAGE_API_KEY)
npm install && npm run migrate && npm run dev
cd ../client && cp .env.example .env.local && npm install && npm run dev
```

Open http://localhost:3000. Without `VOYAGE_API_KEY` the server falls back to a hashing embedding for local dev only; use real embeddings for meaningful scores.

## API

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/register`, `/api/auth/login` | JWT auth |
| POST | `/api/resumes` | Upload PDF/DOCX (multipart `file`), parse, embed |
| GET/DELETE | `/api/resumes`, `/api/resumes/:id` | List, fetch, delete |
| POST/GET | `/api/jobs` | Save and list job descriptions |
| POST | `/api/match` | `{ resumeId, jobId }` returns score, breakdown, gaps, recommendations |
| GET | `/api/matches`, `/api/matches/:id` | History and single result |

## Engineering notes

- Helmet, CORS allow-list, per-route rate limiting, bcrypt (cost 12), file type and size validation
- All request bodies and all LLM outputs validated with Zod (one retry on malformed LLM JSON)
- Per-user data isolation on every query
- Unit tests for scoring, skill normalization, chunking: `cd server && npm test`
- GitHub Actions CI runs the tests on every push
